## ゲーム構成

上部のタイトル「麻雀 · RPG · チップ」を押すと、いつでもゲームを切り替えられます。

### 🀄 麻雀
- 日本のリーチ麻雀を楽しめます。
- 三人東風戦のオンラインとオフラインに対応しています。
- 麻雀牌を使ったパズルを楽しめます。
- 🟡 **ご祝儀チップ**の入手先です。

### ⚔️ RPG
- 放置型RPGを楽しめます。
- 戦闘・伐採・採掘・釣り・収穫・精錬・製作・料理の8つの行動を育てます。
- ゲームを閉じている間も最大12時間まで進行がたまります。
- 毎日の出席チェックとデイリークエストが開きます。
- 🔵 **青チップ**・🟣 **紫チップ**の入手先です。

### ♠️ ポーカー
- テキサスホールデムポーカーの大会に参加できます。
- 3〜10ティアの大会が曜日とティアに応じて開催されます。
- 🔴 **赤チップ**の入手先です。

### 🃏 ブラックジャック
- クラシックブラックジャックを楽しめます(6デッキ、ブラックジャック3:2)。
- 🟡 **ご祝儀チップ** · 🔵 **青チップ** · 🔴 **赤チップ**の入手先です。
- ⚫ **ブラックチップ**で入場します。

## 保存と連携

- Googleアカウントに記録が保存され、PCとスマホで同じ進行度のまま続けて遊べます。
- 各自の記録は本人だけが読み書きできます。
